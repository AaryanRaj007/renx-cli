:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Renx ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-renx](https://github.com/awesome-renx/awesome-renx) และ [renx.cafe](https://renx.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
