| [renx-openai-codex-auth](https://github.com/numman-ali/renx-openai-codex-auth)             | API クレジットの代わりに ChatGPT Plus/Pro サブスクリプションを使用する                                               |

| [renx-devcontainers](https://github.com/athal7/renx-devcontainers)                         | 浅いクローンと自動割り当てポートを使用したマルチブランチ devcontainer の分離                                         |
| [renx-google-antigravity-auth](https://github.com/shekohex/renx-google-antigravity-auth)   | Google Antigravity OAuth プラグイン、Google 検索のサポート、およびより堅牢な API 処理                                |
| [renx-dynamic-context-pruning](https://github.com/Tarquinen/renx-dynamic-context-pruning)  | 古いツールの出力を削除してトークンの使用を最適化する                                                                 |

| [renx-websearch-cited](https://github.com/ghoulr/renx-websearch-cited.git)                 | Google ベースのスタイルでサポートされているプロバイダーにネイティブ Web 検索サポートを追加                           |
| [renx-pty](https://github.com/shekohex/renx-pty.git)                                       | AI エージェントが PTY でバックグラウンドプロセスを実行し、インタラクティブな入力を送信できるようにします。           |
| [renx-shell-strategy](https://github.com/JRedeker/renx-shell-strategy)                     | 非対話型シェルコマンドの手順 - TTY に依存する操作によるハングの防止                                                  |
| [renx-wakatime](https://github.com/angristan/renx-wakatime)                                | wakatime で Renx の使用状況を追跡する                                                                            |
| [renx-md-table-formatter](https://github.com/franlol/renx-md-table-formatter/tree/main)    | LLM によって生成された Markdown テーブルをクリーンアップする                                                         |
| [renx-morph-plugin](https://github.com/morphllm/renx-morph-plugin)                         | Morph による Fast Apply 編集、WarpGrep コードベース検索、コンテキスト圧縮                                            |
| [oh-my-renx](https://github.com/code-yeongyu/oh-my-renx)                                   | バックグラウンドエージェント、事前構築された LSP/AST/MCP ツール、厳選されたエージェント、Claude Code 互換            |
| [renx-notificator](https://github.com/panta82/renx-notificator)                            | Renx セッションのデスクトップ通知とサウンドアラート                                                              |
| [renx-notifier](https://github.com/mohak34/renx-notifier)                                  | 許可、完了、エラーイベントのデスクトップ通知とサウンドアラート                                                       |
| [renx-zellij-namer](https://github.com/24601/renx-zellij-namer)                            | Renx コンテキストに基づいた AI による自動 Zellij セッション命名                                                  |
| [renx-skillful](https://github.com/zenobi-us/renx-skillful)                                | Renx エージェントがスキルの検出と挿入を使用してオンデマンドでプロンプトを遅延ロードできるようにする              |
| [renx-supermemory](https://github.com/supermemoryai/renx-supermemory)                      | スーパーメモリを使用したセッション間での永続メモリ                                                                   |
| [@plannotator/renx](https://github.com/backnotprop/plannotator/tree/main/apps/renx-plugin) | 視覚的な注釈とプライベート/オフライン共有による対話型の計画レビュー                                                  |
| [@openspoon/subtask2](https://github.com/spoons-and-mirrors/subtask2)                              | Renx/コマンドをきめ細かいフロー制御を備えた強力なオーケストレーションシステムに拡張                              |
| [renx-scheduler](https://github.com/different-ai/renx-scheduler)                           | launchd (Mac) または systemd (Linux) を cron 構文で使用して、定期的なジョブをスケジュールする                        |
| [micode](https://github.com/vtemian/micode)                                                        | 構造化されたブレインストーミング → 計画 → セッション継続性のあるワークフローの実装                                   |
| [octto](https://github.com/vtemian/octto)                                                          | 複数の質問フォームを使用した AI ブレインストーミング用のインタラクティブなブラウザ UI                                |
| [renx-background-agents](https://github.com/kdcokenny/renx-background-agents)              | 非同期委任とコンテキスト永続性を備えた Claude Code スタイルのバックグラウンドエージェント                            |
| [renx-notify](https://github.com/kdcokenny/renx-notify)                                    | Renx のネイティブ OS 通知 – タスクがいつ完了したかを知る                                                         |
| [renx-workspace](https://github.com/kdcokenny/renx-workspace)                              | バンドルされたマルチエージェントオーケストレーションハーネス – 16 コンポーネント、1 回のインストール                 |
| [renx-worktree](https://github.com/kdcokenny/renx-worktree)                                | Renx 用のゼロフリクション Git ワークツリー                                                                       |
| [renx-sentry-monitor](https://github.com/stolinski/renx-sentry-monitor)                    | Sentry AI Monitoring を使用して AI エージェントをトレースおよびデバッグする                                          |
